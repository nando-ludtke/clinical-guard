System 1 Local Pre-Filtering + Role-Aware Policy Engine

Zero-PHI-Egress Guardrails for Clinical LLM Applications

clinical-guard sits in front of clinical reasoning LLMs to inspect every incoming prompt locally on CPU before any external API call is made. It combines fast semantic crisis detection, hybrid prompt-injection defense, and ONNX PII anonymization with deterministic role-based routing.

Zero PHI Egress

Safety classification, injection screening, and PII redaction run 100% locally in-cluster. Sensitive patient identifiers never leave your VPC during pre-filtering.

Role-Aware Escalation

Distinguishes layman from medical_professional. Overdose/toxicology queries trigger emergency hotlines for patients, but route to clinical reasoning (with audit flags) for clinicians.

Soft Flag vs. Hard Block

Cosine-margin thresholds separate acute crises (hard_block) from ambiguous medication questions (soft_flag), preventing unnecessary false blocks.

OpenAI Key Modes (for Context Groundedness)

POST /v1/guard/evaluate and GET /health run 100% locally with no external API key. For POST /v1/guard/evaluate_context, two key modes are supported:

  • Server-side env: Set OPENAI_API_KEY in .env (default when no header is sent).
  • Per-request BYOK header: Pass X-OpenAI-Api-Key: sk-... on individual requests to override or supply a client key without storing it server-side.

Endpoint Snippets

POST /v1/guard/evaluate
Header: X-User-Role: layman | medical_professional 
curl -sS -X POST http://localhost:8000/v1/guard/evaluate \
  -H "Content-Type: application/json" \
  -H "X-User-Role: layman" \
  -d '{
    "query": "I took 1000mg Metformin and feel slightly nauseous, is that normal?",
    "session_id": "sess-001"
  }'
import httpx

resp = httpx.post(
    "http://localhost:8000/v1/guard/evaluate",
    headers={"X-User-Role": "medical_professional"},  # or "layman"
    json={
        "query": "Patient took 30 pills of acetaminophen 2h ago, NAC protocol?",
        "session_id": "sess-002",
    },
    timeout=10.0,
)
resp.raise_for_status()
print(resp.json())
